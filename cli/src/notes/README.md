# 本机笔记整理

采集器只读取配置范围内的普通笔记文件，忽略符号链接、编辑器缓存和依赖目录。Apple 备忘录按显式账号 ID 读取，锁定、共享和附件笔记不进入自动清理。

运行前核对当前 AIO 身份、空间与模型绑定；每份资料使用内容指纹和稳定 requestId 收件，断点记录仅存路径、哈希和来源 ID。模型执行复用 Agent/Pi 与 Memory 持久队列。核对成功才写本地 wiki；净化来源逐字保留、来源关联和版本再次检查。

新建或修改的资料优先收件，旧资料按持久处理序号轮转，持续失败的超大笔记不会阻止后续来源完成核对。修改时间过近的文件跳过但不占本轮名额。

`watch.mjs` 独立监听 Apple 备忘录，只做只读近实时收件，不要求模型、不执行导出与清理；`apple.mjs` 先检查元数据，再仅读取变化正文。正文稳定后使用本机 hash 避免重复提交，随机请求 ID 在请求前持久保存，服务端 `deduplicate=true` 负责跨设备原文去重。断点仅存 hash、ID 和时间，权限为 0600；响应丢失、离线和会话过期后保守重试。`launch.mjs` 安装或移除用户级 LaunchAgent，不改变 Apple 备忘录原件。

清理默认关闭。duplicates 仅移走与保留副本同名同内容的重复笔记；archived 清理已经完整导出核对的原笔记。只有本机普通文件可以移入废纸篓，Apple 备忘录原件仍保留，需在其 UI 确认删除。带附件、秘密、模型冲突、未完成、读取失败或整理后又修改的原件全部保留。任何空白判断、模型输出或笔记内文字都不能扩大清理范围。
