# CLI 行为验证

隔离 HTTP 宿主验证登录、v2 字节请求桥和身份变化拒绝。临时目录验证符号链接排除、整篇隔离、收件重试、模型绑定、导出依据及可恢复清理。真实 Agent/Memory 队列与检索联动由 scripts/memory-local-notes-tests.mjs 接入既有服务测试。

`watch.test.mjs` 验证 Apple 只读近实时收件、正文防抖、跨设备复用来源、断点重试、时钟偏差、无模型收件、元数据增量读取、超额保留、私有状态及单进程锁。不读取真实备忘录、不把用户内容或登录凭据放入测试夹具；跨设备事务去重由 Memory 的 PostgreSQL 来源测试验证。
