# 验证与边界

实际使用固定版本 Kotlin Toolchain、真实 Compose canvas、Rust HTTP 服务和 PostgreSQL 验收。

- 服务测试通过：分段 SSE、加密密钥、请求幂等、同会话并发拒绝、取消、无授权地址拒绝、跨租户与跨用户拒绝、错误不泄漏密钥、进程重启恢复和中断状态、无活跃任务的残留状态恢复。
- 浏览器实测通过：桌面 1440×960、移动端 390×844，配置模型、创建会话、发送、停止、刷新持久化、确认/取消删除、断网输入零请求、沙箱隔离、资源仅来自本地且控制台零错误。canvas 截图颜色分别为 919 / 494 种，正文和输入框无横向溢出。
- Compose beta 在部分 Tooltip/弹窗后可访问性定位树会延迟或消失；测试对发送/停止的固定按钮使用真实指针，并在部分流程后刷新重新定位。未完成屏幕阅读器验收。
- 测试服务返回明确的「协议测试片段」，不冒充模型生成；用户预览不注入这些模拟配置，尚未验证真实模型调用。
- 父子命名关系已定义；尚未实现 memory 自动调用、父子联合激活或公网安装。

报告输出到忽略提交的 test-results，不把开发数据库连接、主密钥或真实模型密钥放入报告或截图。
